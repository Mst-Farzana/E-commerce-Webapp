# 🛒 E-Commerce Web Application

A full-featured e-commerce platform built with modern web technologies.

## ✨ Features

- 🎨 **Modern UI** - Tailwind CSS 4 + DaisyUI components
- 🚀 **Fast Performance** - Vite build tool
- 🔐 **Authentication** - JWT-based user authentication
- 🌍 **Multi-language** - Vue I18n support
- 📱 **Responsive Design** - Mobile-first approach
- 🛍️ **Product Management** - Add, edit, delete products
- 🛒 **Shopping Cart** - Add to cart functionality
- 📊 **State Management** - Pinia + Vuex
- 🔄 **Event Bus** - Mitt for component communication

## 🛠️ Tech Stack

- **Frontend:** Vue 3, Vue Router, Pinia, Vuex
- **Styling:** Tailwind CSS 4, DaisyUI
- **HTTP Client:** Axios
- **Auth:** JWT (jwt-decode)
- **Build Tool:** Vite 6
- **Deployment:** GitHub Pages

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Deploy to GitHub Pages
npm run deploy
